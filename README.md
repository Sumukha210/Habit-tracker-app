# Welcome to the Habit Tracker App 👋

A React Native mobile application for tracking daily habits and routines.

## Documentation

- [Getting Started Guide](./docs/getting-started.md)
- [NativeWind Setup](./docs/nativewind-setup.md)

## Quick Start

```bash
# Install dependencies
npm install

# Start the development server
npx expo start
```

## Features

- Track daily habits and routines
- Beautiful UI with NativeWind (Tailwind CSS for React Native)
- Cross-platform compatibility (iOS & Android)

## Technology Stack

- [React Native](https://reactnative.dev/)
- [Expo](https://docs.expo.dev/)
- [NativeWind](https://www.nativewind.dev/)
- [Expo Router](https://docs.expo.dev/routing/introduction/)
